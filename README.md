# CogniStream-Developer-Flow-State-Cognitive-Load-Analytics
CogniStream is a data analytics solution that studies how developers work, when they are most productive, how frequently they take breaks, and what factors affect their concentration.
 Project implementation roadmap
Phase 1 – Requirement analysis
Understand the project objective, identify KPIs, define business questions and dataset requirements.
Phase 2 – Data collection
Collect developer activity data or create a documented synthetic dataset.
Phase 3 – Data cleaning
Handle missing values, duplicates, incorrect data types and inconsistent records using Python.
Phase 4 – Exploratory Data Analysis (EDA)
Analyze productivity trends, working hours, focus scores and cognitive load.
Phase 5 – SQL analysis
Write queries using GROUP BY, JOIN, CTEs, CASE WHEN and aggregate functions.
Phase 6 – Power BI dashboard
Create interactive charts, KPI cards, slicers and analytical reports.
Phase 7 – Insights and recommendations
Identify productivity patterns and suggest ways to improve developer workflows.
Phase 8 – Final submission
Prepare source code, documentation, project report, PPT and final demonstration.
